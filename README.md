# Personal Expense Tracker

A command-line expense tracking application built using C.

## Overview

Personal Expense Tracker is a beginner-level C project designed to manage personal expenses through a command-line interface.

The project focuses on practicing fundamental computer science and C programming concepts.

## Features

- Add new expenses
- View saved expenses
- Search expenses by date
- Calculate total expenses
- Persistent data storage using binary files

## Technologies

- C
- GCC
- Git
- GitHub

## Learning Objectives

- Structures (`struct`)
- File handling (`fread`, `fwrite`)
- Pointers
- Functions and modular programming
- String manipulation
- Basic algorithms
